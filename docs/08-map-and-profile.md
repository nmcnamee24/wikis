# Map And Profile

## Map Purpose

The map is not browsing.

The map is progression.

It shows where the user's curiosity has already gone and makes learning history feel tangible.

## Map Mental Model

The map should feel like:

- a skill tree
- a Civilization technology tree
- a constellation of explored ideas
- a personal knowledge graph

It should not feel like:

- a directory
- a filter page
- a search result view
- a completion checklist

## Map V1

Show:

- explored topics as nodes
- current topic highlighted
- path connections
- pillar colors
- light clustering by pillar
- recent path emphasized

Do not show:

- every available topic
- locked content
- social comparisons
- complex filters

## Map Interactions

V1 interactions:

- tap explored node to revisit topic
- pinch/drag map if implementation allows
- filter chips for All, Science, Literature, Society, History

Optional post-V1:

- collapse by rabbit hole
- named paths
- saved routes
- shareable map snapshot

## Profile Purpose

The profile is a reflection of learning, not a social identity page.

It should answer:

- What have I explored?
- What am I naturally drawn to?
- What was my longest path?
- What topics did I save?

## Profile V1 Metrics

Show:

- Topics explored
- Pillar distribution
- Longest rabbit hole
- Recently explored
- Saved topics

Example:

```text
Topics explored: 2,481

Science: 38%
History: 24%
Society: 22%
Literature: 16%

Longest rabbit hole:
Black Holes -> Entropy -> Information Theory -> Computing
```

## Metrics To Avoid

Avoid:

- follower count
- likes
- public rank
- public streak
- competitive leaderboards
- manipulative daily goals

## Saved Topics

Saved topics are private by default.

Use cases:

- revisit a fascinating topic
- build a collection later
- remember an idea without leaving the feed

Collections can wait until after V1 unless saving feels incomplete without them.
