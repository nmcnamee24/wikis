# Step 08: Build Map, Profile, And Local Memory

## Goal

Make exploration accumulate into a private learning record.

## Build

Screens:

- Map
- Profile

Data:

- local exploration history
- synced exploration events
- saved topics
- pillar distribution
- longest rabbit hole

## Tasks

1. Store every viewed topic locally.
2. Store every gesture transition locally.
3. Sync exploration events to backend.
4. Build map data endpoint.
5. Build profile summary endpoint.
6. Render explored nodes on map.
7. Highlight current topic and recent path.
8. Show topics explored.
9. Show pillar distribution.
10. Show longest rabbit hole.
11. Show recently explored and saved topics.
12. Add revisit behavior from map/profile to feed.

## Acceptance Criteria

- Map reflects actual explored paths.
- Profile updates after new exploration.
- Saved topics persist.
- Longest rabbit hole is accurate.
- No public social metrics exist.
- App still feels simple: Feed, Map, Profile.

## Do Not Build Yet

- Public sharing
- Leaderboards
- Follower graph
- Achievements
- Streak pressure
