# Launch Checklist

## Product

- App opens directly to a topic.
- No onboarding required.
- Feed has only one topic at a time.
- Down/right/left gestures resolve correctly.
- Save works.
- Map reflects explored topics.
- Profile shows exploration metrics.
- Empty, loading, offline, and error states are polished.

## Content

- Starter topic pool reviewed.
- Each card has source IDs.
- Each card has a valid hook.
- Each card has reading seconds.
- High-risk topics are excluded or reviewed.
- Weak images fall back to pillar backgrounds.
- No broken or misleading media.

## Design

- Topic title is the visual hero.
- UI chrome is quiet.
- Pillar colors are consistent.
- Text contrast passes accessibility checks.
- Long titles wrap cleanly.
- Dynamic Type works.
- Reduce Motion mode works.
- VoiceOver labels exist.

## iOS Engineering

- SwiftUI app builds cleanly.
- Core flows covered by tests.
- Crash reporting installed.
- Analytics events implemented.
- Offline cache works.
- Image caching works.
- App state restoration is acceptable.
- No secrets are bundled in the app.
- App icon and launch screen are final.

## Backend

- Topic API deployed.
- Traversal API deployed.
- Event API deployed.
- Database backups enabled.
- Rate limiting configured.
- Monitoring enabled.
- Content admin path exists, even if simple.
- Asset storage and CDN are configured.

## Privacy And Compliance

- Privacy policy written.
- Terms written if accounts or payments exist.
- App Store privacy nutrition labels prepared.
- Account deletion supported if accounts exist.
- Data collection is minimized.
- User exploration history is private by default.

## TestFlight

- Internal testing complete.
- External beta group created.
- Feedback channel ready.
- Crash reports monitored.
- First-session analytics reviewed.
- Topic quality issues triaged.

## App Store

- App name and subtitle finalized.
- Screenshots prepared.
- Description written.
- Keywords selected.
- Age rating completed.
- Support URL ready.
- Marketing URL optional.
- Review notes prepared if needed.
- Build submitted through App Store Connect.
