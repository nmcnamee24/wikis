# Roadmap

## V0 Prototype

Goal:

Prove that the core gesture loop feels good.

Build:

- native SwiftUI feed
- 40 to 100 curated topics in local JSON
- pillar backgrounds
- static graph edges
- save button
- local exploration history
- simple map preview
- simple profile summary

Do not build:

- accounts
- search
- comments
- notifications
- admin tools
- advanced personalization

## V1 Private Beta

Goal:

Validate content quality and traversal behavior with real users.

Build:

- backend topic API
- traversal scorer
- event ingestion
- remote content updates
- explicit edge rebuild pipeline based on the chosen map behavior
- cached approved cards for instant feed loading
- image CDN
- TestFlight distribution
- crash reporting
- analytics
- account optionality or anonymous identity
- improved map
- profile summaries

Content target:

- 500 to 1,500 reviewed topics
- balanced across four pillars
- strong starter pool
- no high-risk unreviewed current topics

## V1 Public Launch

Goal:

Ship a focused curiosity engine with excellent first-session quality.

Build:

- polished feed transitions
- reliable offline cache
- accessibility pass
- privacy policy
- account deletion if accounts exist
- App Store metadata
- App Store screenshots
- release monitoring

## V1.5

Possible additions:

- collections
- better saved topic organization
- named rabbit holes
- map sharing as static image
- more advanced personalization
- limited search for saved/explored topics only

## V2

Possible additions:

- full search
- user-created private paths
- topic request queue
- teacher/parent mode
- spaced resurfacing
- deeper article mode
- multilingual content
- iPad map-first experience
- community-assisted mapping and review

## Features To Delay

Delay until the core loop is proven:

- social graph
- comments
- public profiles
- leaderboards
- achievements
- creator monetization
- daily challenges
- web publishing

These can easily distort the app away from curiosity.
